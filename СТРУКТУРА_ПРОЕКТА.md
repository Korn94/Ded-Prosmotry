# СТРУКТУРА ПРОЕКТА (простыми словами)

**Ded-Prosmotry** — это сайт-аналитика для OK.RU: собирает просмотры ваших видео и
«живость» сообществ, сохраняет их в базу и рисует графики роста.

- **Фронтенд** (то, что видно в браузере) — папка `app/`
- **Бэкенд** (то, что работает «под капотом»: парсит OK.RU и хранит данные) — папка `server/`
- **Общие типы** для связи фронта и бэка — папка `shared/`
- **База данных** (SQLite) — файл `data/analytics.db` (создаётся автоматически)

---

| Папка | Что там |
|-------|---------|
| `app/` | Весь интерфейс: страницы, графики, меню, стили |

## 🎨 `app/` — интерфейс (фронтенд)

| `add-community.vue` | `/add-community` | Вставляете ссылку на сообщество — оно добавляется в базу |

| `passes.vue` | `/passes` | Журнал всех «обходов» (когда и что снималось со статистики) |
| `communities/index.vue` | `/communities` | Список сообществ с метриками, фильтрами и поиском |
| `communities/[id].vue` | `/communities/ID` | Карточка одного сообщества: график, видео, подписчики |
| `videos/[id].vue` | `/videos/ID` | Карточка одного видео: история просмотров, обновление |

## ⚙️ `server/` — бэкенд

### `server/api/` — адреса (эндпоинты)

Имена файлов = адреса. `videos.get.ts` → `GET /api/videos`.
Суффикс `.post.ts` — приём данных, `.get.ts` — получение данных.

| Файл | Адрес | Что делает | Кто вызывает |
|------|-------|-----------|--------------|
| `videos.get.ts` | `GET /api/videos` | Список всех видео | `my-videos`, стор видео |
| `videos.post.ts` | `POST /api/videos` | Добавляет видео по ссылкам (со стримом прогресса) | `add-videos` |
| `videos/[id].get.ts` | `GET /api/videos/:id` | Детали одного видео + история | `videos/[id]` |
| `communities.get.ts` | `GET /api/communities` | Список сообществ с расчётом метрик | `communities/index` |
| `communities.post.ts` | `POST /api/communities` | Добавляет сообщество по ссылке | `add-community` |
| `communities/[id].get.ts` | `GET /api/communities/:id` | Детали сообщества + видео + история обходов | `communities/[id]` |
| `passes.get.ts` | `GET /api/passes` | История обходов (журнал) | `passes` |
| `parse-views.post.ts` | `POST /api/parse-views` | Считает просмотры по ссылкам **без записи** в базу | `parse-views` |
| `update-stats.post.ts` | `POST /api/update-stats` | **Обход**: заново снимает статистику по видео (со стримом) | кнопки «Обновить» |
| `analytics/daily-activity.get.ts` | `GET /api/analytics/daily-activity` | Активность за 30 дней (для графика) | `DailyActivityChart` |
| `analytics/my-videos.get.ts` | `GET /api/analytics/my-videos` | Готовые данные для графиков личных видео | `my-videos` |
| `analytics/community-weekly/[id].get.ts` | `GET /api/analytics/community-weekly/:id` | Недельная аналитика сообщества | `communities/[id]` |

> **Стрим (поток)** — сервер отдаёт прогресс по одной строке за раз (NDJSON),
> чтобы в интерфейсе в реальном времени двигалась полоска прогресса.

### `server/database/` — база данных

| Файл | Что делает |
|------|-----------|
| `db.ts` | Подключается к базе `data/analytics.db` (создаёт папку, если нет) |
| `schema.ts` | **Описание всех таблиц** (это главный файл про структуру базы) |
| `migrations/` | SQL-файлы с изменениями структуры таблиц (генерирует drizzle-kit) |
| `migrations/meta/` | Служебные снапшоты миграций (не править руками) |

**Таблицы из `schema.ts` простыми словами:**

| Таблица | Что хранит |
|---------|-----------|
| `communities` | Сообщества OK.RU (id, название, ссылка) |
| `videos` | Видео (id, ссылка, название, связанное сообщество) |
| `passes` | «Обходы» — разы снятия статистики (когда начали, закончили, ошибки) |
| `measurements` | Конкретные замеры: сколько просмотров было у видео в момент обхода |
| `views_history` | История просмотров по дням (для быстрых графиков) |
| `subscribers_history` | История числа подписчиков сообщества по дням |

### `server/plugins/`

| Файл | Что делает |
|------|-----------|
| `migrate.ts` | При старте сервера **автоматически применяет миграции** (создаёт/обновляет таблицы) |

### `server/services/` — бизнес-логика (между API и базой)

| Файл | Что делает |
|------|-----------|
| `videoService.ts` | Добавление видео, обновление названий |
| `communityService.ts` | Добавление сообществ, обновление числа подписчиков |
| `passService.ts` | Создание и завершение «обходов» (записи в журнал) |
| `measurementService.ts` | Сохраняет результат замера в таблицы `measurements` + `views_history` |

### `server/utils/` — вспомогательное

| Файл | Что делает |
|------|-----------|
| `okRuParser.ts` | **Парсер OK.RU**: заходит на страницу и достаёт просмотры/названия/подписчиков. Таймаут 15с, до 3 попыток только на сетевые ошибки (экспоненциальная пауза) |
| `metricsCalculator.ts` | Считает метрики: тренд (↗/↘) и статус вовлечённости (живое/мёртвое) |
| `ndjsonStream.ts` | Обёртка NDJSON-стрима прогресса: события `start`/`ping` (heartbeat), чтобы фронт видел текущий элемент и не «зависал» при медленном соединении |

## 🛠 `scripts/` — одноразовые утилиты

Запускаются **вручную** из терминала (не при обычной работе сайта).
Нужны редко — обычно только при миграции или восстановлении данных.

| Файл | Что делает |
|------|-----------|
| `migrate-json.ts` | Переносит данные из старого `videos.json` в базу SQLite |
| `refresh-subscribers.ts` | Пересчитывает число подписчиков у всех сообществ |
| `update-titles.ts` | Дописывает названия видео, у которых они пустые |
| `restore-from-backup.ts` | Восстанавливает базу из бэкапов (JSON + выгрузки API) |

## 🚀 Самое важное на каждый день

**Запустить проект:**
```powershell
npm run dev
```
(или просто запустите `запустить.bat` двойным щелчком)

**Куда копать при типичных задачах:**

| Хочу… | Правьте |
|-------|---------|
| Новую страницу | Создайте `.vue` в `app/pages/` — адрес появится автоматически |
| Новый API-эндпоинт | Создайте файл в `server/api/` (имя = адрес) |
| Изменить/добавить поле в базе | `server/database/schema.ts` → затем сгенерируйте миграцию через `drizzle-kit` |
| Новый графиков | Сделайте компонент в `app/components/charts/` |
| Изменить меню | `app/layouts/default.vue` |
| Поправить внешний вид | `app/assets/styles/` (цвета — в `_variables.scss`) |
| Изменить форму данных с сервера | `shared/types/api.ts` (и места, где он используется) |

> **Не трогайте:** `.nuxt/`, `node_modules/`, `data/` (кроме бэкапа), файлы в
> `server/database/migrations/meta/` — это служебное.
