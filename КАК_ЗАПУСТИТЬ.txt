КАК ЗАПУСТИТЬ ПРОГРАММУ
=======================

Программа сама всё скачает и настроит. От вас нужно
только два раза что-то установить один раз, а дальше -
просто запускать файл.

-----------------------------------------------------------
ЧТО УСТАНОВИТЬ ОДИН РАЗ (если ещё не установлено)
-----------------------------------------------------------

Нужны две бесплатные программы: Node.js и Git.
Проще всего: при первом запуске файла программа сама
покажет, чего не хватает, и откроет сайт для скачивания.

НО лучше установить сразу, чтобы не прерываться:

1) Node.js
   - Откройте сайт:  https://nodejs.org
   - Нажмите зелёную кнопку "LTS".
   - Скачанный файл запустите и жмите "Далее / Next"
     до конца, потом "Готово / Finish".

2) Git
   - Откройте сайт:  https://git-scm.com/download/win
   - Нажмите синюю кнопку "64-bit".
   - Скачанный файл запустите и жмите "Далее / Next"
     до конца, потом "Готово / Finish".

ОБЯЗАТЕЛЬНО: после установки закройте все окна и
перезапустите компьютер (это важно, чтобы программы
стали видимыми для системы).

-----------------------------------------------------------
КАК ЗАПУСКАТЬ ПРОГРАММУ (каждый раз)
-----------------------------------------------------------

1. Создайте отдельную папку (например, на рабочем столе
   назовите её "Программа") и положите туда файл
   "запустить.bat".

2. Запустите файл "запустить.bat" двойным щелчком мыши.

3. Откроется чёрное окно. Ничего не нажимайте - программа
   сама скачает проект, установит библиотеки и запустит его.
   Первый запуск самый долгий (5-15 минут), дальше - быстро.

4. Когда в окне появится адрес вида
      http://localhost:3000/
   откройте его в любом браузере (Chrome, Edge, Яндекс).

5. Когда закончите работать - закройте вкладку в браузере,
   вернитесь в чёрное окно и нажмите одновременно Ctrl+C.
   Окно можно закрыть.

-----------------------------------------------------------
ПОЛЕЗНЫЕ ЗАМЕЧАНИЯ
-----------------------------------------------------------

- Ваши данные (база данных) хранятся в папке программы
  внутри папки "код/data". Ничего не удаляйте оттуда,
  если не хотите потерять данные.

- При каждом запуске программа сама проверяет, не вышла
  ли новая версия, и при необходимости обновляется.
  Обычные данные при этом не теряются.

- Если окно закрылось из-за ошибки - просто запустите
  файл "запустить.bat" ещё раз. Обычно помогает.

- Не удаляйте папку "код" и не заглядывайте в неё -
  она нужна для работы программы.
