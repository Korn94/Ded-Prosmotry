# Ded-Prosmotry

Приложение на **Nuxt 4** (Vue 3 + TypeScript) с локальной базой данных **SQLite**.

Это простая пошаговая инструкция для запуска проекта на своём компьютере,
даже если вы раньше ничего не устанавливали и не знакомы с кодом.

---

## Что нужно установить

Для работы нужны всего **две программы**:

| Что | Зачем | Скачать |
|-----|-------|---------|
| **Node.js** (обязательно) | Запускает проект и команду `npm` | [nodejs.org](https://nodejs.org) |
| **VS Code** (рекомендуется) | Редактор кода, в котором удобно работать с проектом | [code.visualstudio.com](https://code.visualstudio.com) |

---

## Шаг 1. Установка Node.js

1. Откройте сайт <https://nodejs.org>.
2. Нажмите зелёную кнопку **«LTS»** (это стабильная версия — подойдёт для Nuxt 4).
3. Скачайте установщик `.msi` для Windows и запустите его.
4. В мастере установки просто жмите **Next / Далее** до конца и нажмите **Finish**.
   Все галочки по умолчанию менять **не нужно**.

> ⚠️ После установки обязательно **перезапустите VS Code** (если VS Code установлен - шаг 2) или откройте новое
> окно терминала, иначе команда `node` может не найтись.

### Проверка установки Node.js - можно пропустить

Откройте **PowerShell** (или терминал в VS Code) и введите по очереди:

```powershell
node -v
npm -v
```

Если установка прошла успешно, вы увидите номера версий, например:

```
v22.14.0
10.9.2
```

Если вместо версии выводится текст вроде *«node is not recognized…»*,
значит Node.js не установился или нужно перезапустить терминал/компьютер.

---

## Шаг 2. Установка VS Code (рекомендуется)

1. Скачайте VS Code с <https://code.visualstudio.com>.
2. Запустите установщик и жмите **Далее / Next** до конца.
   На шаге **«Выберите дополнительные задачи»** включите галочку
   **«Добавить в PATH»**.
3. Завершите установку (кнопка **Finish / Готово**).

---

## Шаг 3. Открытие проекта

Есть два варианта:

**Вариант А — через VS Code (рекомендуется):**
1. Запустите VS Code.
2. Нажмите **File → Open Folder…** (Файл → Открыть папку).
3. Выберите папку проекта (ту, где лежит файл `package.json`) и нажмите
   **Select Folder / Выбрать папку**,
   либо просто перетащите папку проекта из проводника в открытое окно VS Code

**Вариант Б — через командную строку:**
```powershell
cd "путь\к\папке\проекта"
```

---

## Шаг 4. Установка зависимостей (пакетов)

Установка нужна **один раз**. В терминале (в папке проекта) выполните:

```powershell
npm install
```

Эта команда скачает все библиотеки проекта в папку `node_modules`.
Она может занять несколько минут — это нормально.

> Если во время установки появится ошибка про `node-gyp` или `better-sqlite3`
> (нужны компиляторы для Windows), см. раздел **«Решение проблем»** ниже.

---

## Шаг 5. Запуск проекта

В терминале (в папке проекта) выполните:

```powershell
npm run dev
```

Проект начнёт сборку, и при первом запуске **автоматически**:

1. создаст папку `data/` с базой данных `analytics.db`;
2. применит миграции (структуру таблиц) — в выводе появится строка
   `[БД] Миграции успешно применены / база данных актуальна`.

Когда всё будет готово, в терминале появится адрес, например:

```
Local: http://localhost:3000/
```

Откройте этот адрес в браузере (обычно <http://localhost:3000>) — проект работает.

> ✅ Не закрывайте окно терминала, пока пользуетесь проектом.
> Чтобы остановить сервер, нажмите `Ctrl + C` в этом терминале.

---

## Шаг 6. Как открыть проект снова

Повторно запускать нужно только **шаг 5** (`npm run dev`).
Устанавливать Node.js и зависимости заново не нужно.

## Команды проекта

| Команда | Что делает |
|---------|-----------|
| `npm run dev` | Запускает проект в режиме разработки (обычно порт 3000) |
| `npm run build` | Собирает финальную версию проекта |
| `npm run preview` | Показывает собранную версию локально |
| `npm install` | Устанавливает зависимости (нужно при изменениях в `package.json`) |

---

## Где хранятся данные

- База данных — файл `data/analytics.db`.
- Он создаётся автоматически при первом запуске, ничего делать вручную не нужно.
- Если нужно «обнулить» данные, можно остановить сервер и удалить файл
  `data/analytics.db` — при следующем запуске база создастся заново и будут
  применены миграции.

## Решение проблем

### Ошибка установки `better-sqlite3` / `node-gyp`
`better-sqlite3` — это модуль с нативным кодом. Если скачивание готовых
бинарников не сработало, Windows просит установить компиляторы:

1. **Вариант 1 (самый простой):** удалите папку `node_modules` и переустановите
   зависимости — чаще всего подтягиваются готовые собранные файлы:
   ```powershell
   Remove-Item -Recurse -Force node_modules
   npm install
   ```
2. **Вариант 2:** установите среду для сборки — [Visual Studio Build Tools](https://visualstudio.microsoft.com/ru/downloads/#build-tools-for-visual-studio-2022).
   При установке отметьте **«Средства сборки для C++» (C++ build tools)**
   и снимите всё остальное. После этого повторите `npm install`.

### Ошибка «Port 3000 is already in use»
Порт занят другой программой. Остановите её или запустите проект на другом порту:

```powershell
npm run dev -- --port 3001
```

### «node is not recognized / не является внутренней командой»
Node.js не найден. Перезапустите терминал или VS Code. Если не помогает —
перезапустите компьютер (иногда путь PATH обновляется не сразу).

### Ошибка про версию Node.js
Nuxt 4 требует **Node.js 20.19+ или 22.12+**. Проверьте версию командой
`node -v` и обновите Node.js с официального сайта, если версия старая.

## Подсказки новичку

- **Что такое терминал?** В VS Code: меню **Terminal → New Terminal**
  (Терминал → Новый терминал). Он открывается прямо в папке проекта.
  Можно еще открыть с помощью горячих клавишь - CTRL + J
- **Папка `node_modules`** — это временные установленные библиотеки.
  Не редактируйте её и не заглядывайте туда — она не входит в код проекта.
- **Куда писать код?** Основной код находится в папках `app/`, `server/`,
  `shared/`. При сохранении файла проект **автоматически пересобирается**
  (hot reload) — обновления появляются в браузере без перезапуска.
